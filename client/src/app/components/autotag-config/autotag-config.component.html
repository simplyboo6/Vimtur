Support is the number of manually tagged examples the calibration run used for this tag. Quality (AUROC) measures how well the tag's score ranks correctly tagged media above everything else — 0.5 is random, 1.0 is perfect.

Threshold is the similarity score above which the tag is applied to an image. Zero does not switch a tag off — scores are almost always positive, so it would apply nearly everywhere. A row is only applied automatically while it holds a calibrated threshold from a run that met the floor: "Review (low support)" and "Not calibrated" rows are inert while they hold those statuses. Typing a threshold into such a row switches its status to Manually overridden and applies the tag as-is — an explicit override at noticeably worse precision; clearing the field restores the calibration outcome. To clear the floor properly, add tagged examples and re-run calibration, or lower the Minimum calibration support above.

Descriptions define what the encoder looks for. Every entry is scored alongside the bare tag and "a photo of {tag}", which the server always includes without storing them here — keep them short (limited to 60 characters here). Thresholds and support counts come from the calibration task; rows flagged "Review (low support)" need better wording or more tagged examples before their tags can apply automatically. A tag's config entry is kept when the tag is deleted and is cleared at the next calibration run.
